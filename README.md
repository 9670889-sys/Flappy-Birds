A Flappy bird-like with multiple playable characters, whichever character flies the longest wins!

This game is for competitive players who fight over who is the better brawler bird.

The user should play brawler bird with it.

One key input is clicking or pressing the up button which will result in jumping.

To be considered a success, we would have to have a working version would be a fully functioning brawler bird, when they die, the icon changes, the score is recorded, and the next player plays at the bare minimum.

We need to research the different classes, how to program gravity, and how to implement delta time.
