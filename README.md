# Flappy-Birds

![Title](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRB-iXw-QpO0fBwXOPIRxK-ahSCOVpmnRea0Okr2H_ZhA&s=10)

Flappy bird with multiple playable characters, whichever character flies the longest wins!

This game is for competitive players who fight over who is better at flappy bird.

The user should play flappy bird with it.

One key input is clicking or pressing the up button which will result in jumping.

The smallest working version would be a compeletly functioning flappy bird, when they die, the icon changes, the score is recorded, and the next player plays at the bare minimum.

We need to research the different classes, how to program gravity, and how to implement delta time.
